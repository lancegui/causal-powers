# Stage 3 primary DiD result

The v2 estimated average policy effect is -4.334462 opioid-prescribing rate points per 100,000 per month (state-clustered SE 0.441454; 95% CI [-5.227386, -3.441537]; p = 4.28625e-12).

This state-and-month fixed-effects DiD compares the post-adoption change in the 20 adopting states with the contemporaneous change in the 20 never-adopting states. Under parallel untreated trends, no spillovers, and no coincident adopting-state shocks, the updated data imply a reduction of about 4.33 prescriptions per 100,000 per month. The main limitation remains the untested counterfactual-trend assumption.
