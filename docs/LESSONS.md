# Lessons

A running log of silent failures that actually bit a real analysis, captured at
the end of each project (see `result-verification` → "Capture what bit you").
The manual, no-machinery version of ECC's `/evolve`: record the lesson here, and
when it generalizes, fold it into the relevant skill (a new red-flag or a sharper
check) so the whole family improves.

One line per lesson:
